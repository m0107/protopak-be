# Architecture Overview

This project follows a microservices-based architecture with separate modules for user management, reporting, and transaction management. The backend is built using Node.js with Express, while the frontend is implemented using React and Redux.

### Components
- **Frontend**: React-based UI with Redux for state management.
- **Backend**: Node.js with Express.js to handle requests.
- **Database**: PostgreSQL for relational data storage, Redis for caching, MongoDB for casino transaction logs.
- **Authentication**: JWT for stateless authentication.
- **External APIs**: Integration with external services like payment gateways.
